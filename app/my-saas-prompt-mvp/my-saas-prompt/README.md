# my-saas-prompt

Pacote gerado pelo Framework Pegada de Silicio.

## Perfil escolhido

Meu Primeiro MVP

## Como usar

1. Envie esta pasta completa para o modelo de inteligencia artificial que vai construir o projeto.
2. Peca para a IA comecar lendo o arquivo `Prompt.txt`.
3. A IA deve seguir `Project.md` como especificacao do produto.
4. A IA deve seguir os arquivos em `config/` como contexto tecnico e arquitetural.
5. Nao edite manualmente a pasta `storage/`; ela deve ser usada apenas como armazenamento de runtime.

## Arquivos principais

- `Project.md`: requisitos do projeto preenchidos no formulario.
- `Prompt.txt`: ordem de execucao para a IA.
- `config/TechSpecsConfig.md`: stack, arquitetura e convencoes tecnicas.
- `config/DockerConfig.md`: orientacoes para Docker e compose.
